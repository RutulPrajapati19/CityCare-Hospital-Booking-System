# CityCare Hospital Booking System

### Business Analyst Portfolio Project

## 1. Project Overview

CityCare Hospital Booking System is a Business Analyst portfolio project focused on improving the hospital appointment booking and management process.

The project analyses existing business problems and proposes a digital booking solution to make appointment management more organised and efficient.

## 2. Business Problem

The existing appointment process may involve:

- Phone-based appointment booking.
- Manual appointment registers.
- Risk of double booking.
- High receptionist workload.
- Difficulty managing doctor schedules.
- Lack of automated patient reminders.

## 3. Project Objectives

- Propose a 24/7 appointment booking solution.
- Reduce manual receptionist work.
- Improve appointment management.
- Provide better visibility into appointment data.
- Support management decisions through reporting.

## 6. Database Design

The database contains four main tables:

- Departments
- Doctors
- Patients
- Appointments

The project uses SQL to analyse appointment trends, booking channels, doctor workload and no-show rates.

## 7. Power BI Dashboard

The dashboard contains three analytical pages:

1. Hospital Overview
2. Booking and Doctor Analysis
3. Management Insights

Key metrics include total appointments, appointment status, booking channels, doctor workload and no-show rates.

## 8. Testing

The project includes 20 designed test cases covering 10 functional areas.

These test cases have been documented but not executed because this is a Business Analyst portfolio case study and does not include a running application.

## 9. Project Limitations

- This is a proposed business solution, not a deployed hospital application.
- The dataset contains fictional sample records.
- No real patient information is used.
- Test cases are designed but not executed.
- Dashboard findings are based on sample data.
